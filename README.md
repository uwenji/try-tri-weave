# Try-Tri-Weave Tool
https://uwenji.github.io/try-tri-weave/web/
Localised Swift–Hohenberg patterns on curved surfaces, for planning triaxial (Kagome) weaves: plant one singularity,
let the hexagonal lattice grow from it, read off sites, singularities and laths. Runs in the browser (WebGPU, with a
CPU fallback).

- `web/` - the app; start with `web/HOW_TO_START.md`, details in `web/README.md`
- run it locally: `python web/serve.py`, then open http://localhost:8080/

Feedback is welcome - please open an issue.
