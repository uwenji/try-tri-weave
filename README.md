# Try-Tri-Weave Tool
https://uwenji.github.io/try-tri-weave/web/
The 6-rosy & Swift–Hohenberg method on curved surfaces, for planning triaxial (Kagome) weaves, reduce weave singularity,
let the hexagonal lattice grow from it, read off sites, singularities and laths. Runs in the browser

more detail please read in [Tri-Weave-Lattice-Equations.html](https://uwenji.github.io/try-tri-weave/web/Tri-Weave-Lattice-Equations.html) (also `6 Explain` in the app's left bar; source `web/Tri-Weave-Lattice-Equations.html`)
and more about our group: https://royaldanishacademy.com/en/case/kagome-architectures
Feedback is welcome - please open an issue.
